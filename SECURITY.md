# Security Policy

CyberTech 360 contains cybersecurity/GRC demonstration code and a production architecture reference.

## Do not commit
Passwords, API keys, service-role credentials, cardholder data, confidential evidence, health information or government identifiers.

## Production controls
MFA/SSO, RBAC, tenant isolation, server-side authorization, CSP/security headers, validation, rate limiting, secret scanning, dependency scanning, SAST/DAST, immutable audit logging, encrypted evidence storage, backup and disaster-recovery testing.

## Vulnerability reporting
Report suspected vulnerabilities privately through the repository owner rather than publishing sensitive exploit details in an issue.
